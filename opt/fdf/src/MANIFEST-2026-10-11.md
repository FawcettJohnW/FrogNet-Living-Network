# What this tree is (2026-10-11), from /

One tar, extracted at the repo root (or at / on an x86 node). The FD&F build in it is `fdf-2026-10-11-r19-a15`: r19
(optimization) + the Android/FD&F thread through a15. It includes everything from the r20 merge (a4's 5 s keepalive and
leaf address from the region); r20 is superseded.
