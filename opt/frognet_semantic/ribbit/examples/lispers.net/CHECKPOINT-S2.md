## What S2 is
ribbit_cpp/semcodec.hpp (header only, links liblz4), ribbit_cpp/pyval.hpp (Python value model: None, bool, int64 or
unbounded decimal int, float, str as UTF-8/WTF-8, bytes, list, insertion-ordered dict), ribbit_cpp/pyuni_tables.hpp
(generated by tools/gen_pyuni_tables.py from Python 3.12.3 / Unicode 15.0.0: int() whitespace and decimal digits).
Ported: encode_request / encode_reply (full), encode_request_diff / encode_reply_diff (reference None / {} / dict,
_values_equal rules), encode_error_reply / decode_error_reply (Python int() parsing), decode_request / decode_reply
(clamped slices, reference merge, "field<i>" names), _lz4_smart and lz4.frame compress/decompress as python-lz4 calls
liblz4, json.dumps (compact, ensure_ascii=False, float repr) and json.loads (the C scanner's grammar). Nothing calls it
yet; S4 wires it into frogram.

## Performance (artifacts/performance-S2.txt; measured, 1-core container, not AI-Host; codec only)
Median ns/op, C++ / Python: encode 5 fields 550 / 6,197; diff identical 428 / 2,715; diff one changed 732 / 4,415;
encode 40-key JSON dict 2,751 / 11,759; encode 4000 B str with LZ4 1,071 / 3,316; decode 5 fields 741 / 4,119;
decode diff + reference 547 / 1,866; decode 40-key dict 4,862 / 7,828; decode 4000 B LZ4 726 / 2,432.
The first measurement (performance-S2-before-perf.txt) had C++ SLOWER than Python on LZ4 decode (10,958 vs 2,695) and
at parity on JSON. Causes found by timing the pieces: byte-at-a-time UTF-8 decode, a new LZ4 context per call, a linear
duplicate-key search, byte-at-a-time JSON escaping. Fixed, then the whole verification above re-run on the final code.

## Not claimed / representation limits (stated in the header)
- Byte identity of compressed frames needs the same liblz4 on both sides (1.9.4 here); decompression does not.
- Nesting deeper than 900 raises RecursionError (Python's own limit depends on its stack, ~1000); not tested at the edge.
- C++ strings that are not UTF-8/WTF-8 have no Python form; they raise EncodeError where Python would encode.
